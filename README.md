# Mobile Client Interface

This directory contains the mobile client interface for the shopping project.

## Components
- `mobile_client_interface.js`: React Native component for the mobile client interface.
- `mobile_api_integration.js`: React Native component for integrating with the backend API.

## Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the application:
   ```bash
   npx react-native run-android
   ```

## Testing

1. Run tests:
   ```bash
   npm test
   ```
